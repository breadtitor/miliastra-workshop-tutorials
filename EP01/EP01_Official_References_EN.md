## Interface notes from this recording

The creator button reads **My Miliastra** in this client; some guide wording uses **My Miliastra Wonderland**. The nearby **Wonderland** button opens stage browsing. **Zoom** in object Transform means scale. The blue marker inspected during capture was **Create Preset Point**, with one spawn-point reference; blue icons should not be assigned a universal meaning. This lesson does not edit spawn configuration or claim a new-account unlock procedure.
